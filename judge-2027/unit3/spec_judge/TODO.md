# JML–JML 评测机组件开发计划

本计划自 2026-10-14 起记录 `judge-2027/` 的开发工作。学生练习 Web 和 JML–Java / OpenJML 验证由协作者维护；本组件负责评测机上的参考 JML 与学生 JML 一致性判定。

## 本轮：从 Web 依赖中独立

- [x] 将 `followUser` 的权威参考合同和回归样例收进本目录，Suite 与正式回归测试不再读取 `Agent/`。
- [x] 将第五个 `unfollowUser` Suite 的正确、错误和质量预检纳入正式回归。
- [x] 明确 CLI 提交格式：UTF-8 的 `.jml` 或带 JML 的 `.java`，包含目标方法声明；支持从标准输入接收源码。
- [x] 为 JSON 结果增加格式版本和 `PASS` / `FAIL` / `ERROR` 状态；配置与输入读取错误不返回学生分数。
- [x] 提供仅包含 JML–JML 组件的独立发布包，以及不依赖 OpenJML 的正式测试命令。
