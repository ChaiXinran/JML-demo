# 2027 独立 JML 题压力测试

这里保存 HW9 签到、HW10 座位预订、HW11 连座查询的模拟学生提交。每个样例在执行前按题意标定预期结果。语义反例的说明给出违反的要求或一组能区分正误的输入。语法与资源样例按评测器公开的提交规则标定。

从 JML-demo 根目录运行：

```sh
python3 -B judge-2027/stress_2027/run.py
```

默认用 4 个并发进程，每次调用限时 10 秒。可用 `--week hw10` 只测一周，或用 `--jobs 8 --repeat 3` 检查重复并发评测。用 `--judge-dir /path/to/spec_judge` 可以核对解压后的评测包。

每轮结果保存在 `runs/` 下的新目录。目录中包含可单独提交的 `submissions/<周次>/<样例>/JML/JML.java`，以及每次调用的 stdout、stderr、退出码和耗时。先看 `report.md` 的差异列表，需要进一步排查时查 `report.json`。运行产物由 Git 忽略。若要指定保存位置，使用 `--output-dir` 并选择尚不存在的目录。

脚本退出码 `0` 表示全部反馈与独立预期相符，`1` 表示存在差异，`2` 表示批量脚本自身无法开始或完成测试。生成的报告区分错放、错杀、语言子集限制、诊断不符、超时和评测端错误。这是教学组内部测试资料。
